# 9. Every existing project file explained

This inventory covers **428 files** in llm-final as it existed when the study notes were made on 8 October 2026. It includes every source module, written document, root log, added-data file, saved experiment and compiled Python copy.

The new explanation lessons are listed in [Start here](README.md). The linked .venv and cache trees are software/download storage and are explained collectively below; their thousands of dependency files are not extra project documents.

Do not read all the tables in order. Search for the exact filename you need. Start with the paper, selection_manifest.json, the selected predictions/errors and the confusion matrix.

## Decode the experiment filenames

| Part                           | Meaning                                                                  |
| ------------------------------ | ------------------------------------------------------------------------ |
| random / grouped               | Which partition regime was used                                          |
| bare                           | A comparison with no decision rules                                      |
| full                           | Best validation-selected system within a model family                    |
| selected                       | Overall validation winner for that regime                                |
| metadata                       | Comparison of keyword availability and rule additions                    |
| rules                          | Fixed base model, different decision rules                               |
| clinical / stripped / all      | No keyword features / first specialty tag removed / all keyword features |
| 0.3 / 1.0 / 3.0 / 10.0         | Value of C                                                               |
| True / False                   | Balanced class weights enabled / disabled                                |
| none / keyword / memory / both | Model only / fixed keyword / repeated-note exclusion / both              |
| learned_keyword / learned_both | Policies with fitting-learned keyword mapping                            |
| validation.npz                 | Candidate scores used for choosing settings                              |
| test.npz                       | Candidate scores for the labelled internal test, not the official file   |
| report.json                    | Metrics calculated from predictions                                      |
| predictions.csv                | Case-level predicted labels, gold labels and routes                      |

Example: random_rules_wordchar_svm_clinical_0.3_True_both_report.json means random regime, fixed-base rule comparison, field SVM without keyword features, C=0.3, balanced weights, both fixed rules, saved test metrics.

NPZ files are numerical data, not readable prose. Their source IDs and label list identify each row and score column. SVM margins are not probabilities.
